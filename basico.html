El lenguaje HTML sirve para aportar contenido y estructura a un documento web

Etiquetas básicas

Agrupar elementos en línea: <span>. Se utiliza para agrupar textos y otros elementos en línea.
Cursiva o énfasis: <em>. El texto aparecerá en cursiva.
División: <div>. Permite dividir la página en secciones.
Negrita o texto destacado: <strong>. El texto aparecerá en negrita.

Párrafo: <p>. Representa un párrafo y solo puede englobar elementos en línea.


Salto de línea: <br>. Fuerza un salto de línea en el texto. No tiene etiqueta de cierre.

Separación horizontal <hr>. Elemento de bloque que dibuja una línea de separación horizontal en la página.

Subíndice: <sub>. El texto que engloba esta etiqueta representa un subíndice.
Subrayado: <u>. El texto al que se aplique esta etiqueta aparecerá subrayado.
Superíndice: <sup >. El texto englobado se convierte en superíndice.
