Pasos para realizar un commit y push en Git

  1. Crear o modificar los archivos del proyecto.
  2. Comprobar los cambios realizados.
  3. Añadir los archivos al área de preparación con el comando git add.
  4. Crear un commit con el comando git commit.
  5. Subir los cambios al repositorio remoto utilizando git push.
